# Skill: weekly idea generation

**Trigger:** step (d) of the weekly content review, or "generate content ideas".
**Goal:** find fresh formats (visual + on-screen text) for next week's 4 x 5 plan. Only look at sources added since the last run.

## Sources (built-in browser)
1. **Post Inspo Megafolder** (Notion): `https://app.notion.com/p/troylouis/Post-Inspo-Megafolder-2c5474a4eb6680059d02e1577a69d64e`
   - Rows have sequential IDs (#705 = newest); the default "All Posts" view lists newest first.
   - Read only rows with ID above `megafolder_last_id` in `logs/inspo-seen.md`.
   - Keep rows that fit: rock / indie / alt genre, asset type we already have or can shoot cheaply (selfie, guitar performance, photo booth, city/subway, bedroom).
2. **Instagram saved** (personal account `ahansolocups`, logged in): collections "music market inspo" and "music visuals". Newest saves first; stop at the last link in `logs/inspo-seen.md`. Open each reel, screenshot at 0.5 scale to read the on-screen text and visual.
3. **Band Instagram saved** (`daisysroom.band`, collection "music marketing": `https://www.instagram.com/daisysroom.band/saved/music-marketing/2218107325399654/`). Same method.
4. **TikTok favorites**: same method once the right account is confirmed.

## Speed rules
- Saves are read once and cached in `logs/inspo-library.md` (link, on-screen text, visual, hook type). Never re-read a cached link.
- Weekly runs only open saves newer than the watermark, usually a handful.
- Batch 7 reels per browser call, screenshot at 0.4 scale.

## Uprank rule
Tag every hook with a hook type (e.g. location-CTA, retention-ask, anti-AI, identity, POV, list-of-reasons, nostalgia). A Megafolder idea whose hook type also appears in Ahan's saves gets upranked in next week's plan.

## For each candidate, capture
source link | visual | on-screen text (verbatim) | why it works | footage needed (existing / new) | which of our sections it suits

## Pick
- Each week deliver **5 video formats + 1 TikTok carousel format**, enough to replace the formats being cut.
- Output as a table: # | text (Ahan's version) | visual | footage (existing / new) | original link as [▶ Watch](url). Mark upranked ideas with ⬆️.
- Adapt the text to Daisy's Room in Ahan's voice (lowercase, casual). Keep the mechanic, change the words.
- Prefer ideas that drive comments or sends (questions, "lmk what city", "copy link") and need no new gear.
- Never reuse an idea already listed in `logs/inspo-seen.md`.

## After the run
Update `logs/inspo-seen.md`: new `megafolder_last_id`, last processed link per source, and one line per idea used.
